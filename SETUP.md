To setup the testing environment, clone the GitHub repository and download Node.js from https://nodejs.org/en. Open the project in a code editor of choice, and run 'npm install' in the project folder and the server folder to download any neccessary packages. A .env folder needs to be setup in the server folder to connect to the database and S3 bucket. In the .env file, create variables called CONNECTION, AWS_BUCKET_NAME, AWS_ACCESS_KEY_ID, and AWS_SECRET_ACCESS_KEY. These credentials will be desginated by the database and S3 bucket owner.

To run the frontend app, use the command 'npm start' in the outer project folder. To start the server, use the command 'node server.js' in the server folder, or download nodemon (automatically restarts server after changes) using 'npm install nodemon', and run the server using 'nodemon server.js'.
