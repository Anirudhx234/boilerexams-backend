To set up the development environment, clone the GitHub repository and download Node.js from https://nodejs.org/en and PostgreSQL 15 from https://www.postgresql.org/download/. Open the project in a code editor of choice, and run 'npm install' in the server folder to download all necessary packages. A .env folder needs to be set up in the server folder to connect to the database and S3 bucket. In the .env file, create variables called DATABASE_URL, AWS_BUCKET_NAME, AWS_ACCESS_KEY_ID, and AWS_SECRET_ACCESS_KEY. Create a local database using the psql shell and set DATABASE_URL to a connection string in the format of "postgresql://<user>:<password>@localhost:<port_number>/postgres?schema=public". After this, run "npx prisma migrate dev", and your local database is ready for development. An administrator will designate S3 bucket and production database credentials.

To start the server, use the command 'npm start', or download nodemon (automatically restarts the server after changes) using 'npm install nodemon', and run the server using 'nodemon server.ts'.
